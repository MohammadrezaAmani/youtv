# ارتقای YouTV از نسخه 0.4 به 0.5 — Bun

## تغییرات

- ضبط محلی از ویدئوی **واقعاً در حال پخش** با `MediaRecorder` و `HTMLVideoElement.captureStream` در مرورگرهای سازگار؛ شروع، توقف موقت، ادامه، پایان، نمایش زمان و حجم.
- انتخاب بیت‌ریت خروجی ضبط (۱٫۵، ۳، ۴، ۶، ۱۰ Mbps)؛ این تنظیم در LocalStorage و Backup هم ذخیره می‌شود، اما **کیفیت منبع HLS را تغییر نمی‌دهد** و فقط به Encoder مرورگر پیشنهاد داده می‌شود.
- ذخیره مستقیم به فایل با `showSaveFilePicker` در مرورگرهای سازگار (معمولاً Chromium روی HTTPS/localhost). در سایر مرورگرها، ساخت فایل WebM/MP4 از قطعات MediaRecorder و تلاش برای دانلود؛ دکمه دانلود دوباره نیز نمایش داده می‌شود. حجم حافظه حالت دانلود به ۳۵۰ MiB محدود است.
- ضبط هنگام بسته شدن تب یا مرورگر ادامه نمی‌یابد، زمان‌بندی در پس‌زمینه و ضبط هم‌زمان چند شبکه در این نسخه وجود ندارد؛ باید صفحه باز و شبکه در حال پخش باشد.
- ضبط بر پایه تصویر/صدا است، نه دانلود مستقیم قطعات TS؛ امکان تفاوت Codec/Bitrate وجود دارد. زیرنویس‌های جانبی، Teletext و DRM الزاماً در خروجی نیستند. محدودیت CORS/Protected Media برقرار است.
- تبدیل تمام کنترل‌های عادی داخل صفحات React به کامپوننت‌های اختصاصی YouTV: `Select` و `SelectOption` مبتنی بر Radix، `Input`، `Textarea`، `Checkbox`، `RadioOption`، `Slider`، `FileInput`، `ActionButton` و `ProgressBar`؛ `DatePicker` مستقل نیز برای فرم‌های بعدی آماده است. عناصر زیرساختی مثل `video`، `track`، `form` و `label` معنای بومی خود را حفظ می‌کنند.
- رفع خطاهای TypeScript گزارش‌شده: Picture-in-Picture، ورودی Secret در Cloudflare، زبان‌های ترجیحی صدا/زیرنویس، `detail` تست اتصال.
- رفع تست صادرات M3U با حذف `youtv-tags` خالی، ولی نگهداری تگ‌ها در خروجی کانال‌های دارای تگ.
- برای جلوگیری از خطای Radix، مقدار خالی `SelectOption` به مقدار داخلی غیرخالی تبدیل و هنگام رویداد دوباره به رشته خالی برگردانده می‌شود.

## اعمال Patch

با توجه به مسیر نصب مشاهده‌شده در لاگ ارسال‌شده:

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.4.0-to-v0.5.0.patch
git apply ~/Downloads/YouTV-v0.4.0-to-v0.5.0.patch

bun install
bun run check
bun run test
bun run build
bun run dev
```

**پیش‌نیاز:** پروژه باید قبلاً Patch نسخه v0.4 را داشته باشد. فایل‌های `default.m3u8`، Worker و کتابخانه شخصی تغییر داده یا حذف نمی‌شوند.

## ضبط شبکه

1. کانال را باز کن و منتظر شروع واقعی پخش باش.
2. از بخش *Channel recording* بیت‌ریت را انتخاب کن.
3. روی **Record** بزن. اگر مرورگر امکان ذخیره مستقیم دارد، نام و محل فایل را انتخاب کن.
4. برای توقف موقت از **Pause** و برای ادامه از **Resume** استفاده کن.
5. با **Stop & save** ضبط را ببند؛ فایل در مسیر انتخابی یا پوشه دانلود قرار می‌گیرد.
6. اگر دانلود خودکار مسدود شد، از **Download recording** استفاده کن.

**هشدار:** در حالت بدون File System Access و برای فایل‌های بزرگ، ضبط به محدودیت ۳۵۰ MiB می‌رسد و کلیپ برای ذخیره بسته می‌شود. تا قبل از ذخیره نهایی، صفحه را نبند.

## محدودیت اعتبارسنجی

سینتکس تمام فایل‌های TypeScript/TSX بررسی شده و تست‌های logic سرویس ضبط با شبیه‌ساز API بررسی می‌شوند. اما در محیط ساخت فعلی Bun و وابستگی‌های واقعی پروژه نصب نیستند؛ بنابراین `bun run check`، `bun run test` و Build مرورگر در این محیط اجرا نشده‌اند. نتیجه آن‌ها باید روی سیستم کاربر بررسی شود و هر خطا با لاگ اصلاح شود.
