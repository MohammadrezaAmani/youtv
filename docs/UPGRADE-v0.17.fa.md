# YouTV v0.17 — رفع خطای QuotaExceeded

## علت

نسخه‌های قبلی کل کتابخانه (شبکه‌ها، پلی‌لیست‌ها، نتایج اسکن و تنظیمات) را در یک کلید `localStorage` ذخیره می‌کردند. محدودیت ظرفیت Web Storage در مرورگر باعث `QuotaExceededError` / `The quota has been exceeded` می‌شد؛ این خطا به معنی وجود محدودیت ۱۵ مگابایتی در فایل‌های M3U نیست.

## اصلاحات

- مهاجرت ذخیره‌سازی اصلی به IndexedDB با ذخیره ساخت‌یافته؛ بدون سقف ثابت تعداد کانال یا اندازه کل کتابخانه در کد YouTV.
- انتقال خودکار اطلاعات قبلی از `localStorage['youtv:v1']`، بدون حذف فایل قدیمی قبل از Commit موفق IndexedDB.
- تجمیع تغییرات پی‌درپی و ثبت آخرین Snapshot، بدون اجرای `JSON.stringify` کل کتابخانه در هر تغییر کوچک.
- نمایش هشدار هنگام بروز خطای واقعی ذخیره‌سازی و امکان گرفتن Backup از داخل برنامه.
- حذف سقف تعداد Tags، ترک‌های زیرنویس، لینک‌های جایگزین و محدودیت مصنوعی طول تاریخچه پخش.
- حذف سقف ۲ مگابایت برای زیرنویس و بازنویسی Manifestهای HLS و سقف ۱۵۰ کیلوبایت Teletext.
- به‌روزرسانی Worker قابل کپی/دانلود از داخل کلاینت.

## نصب

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.16.0-to-v0.17.0.patch
git apply ~/Downloads/YouTV-v0.16.0-to-v0.17.0.patch

bun install
bun run check
bun run test
bun run build
bun run dev
```

> Patch مستقل از اصلاح یک‌خطی `TS2322` فایل `playlist.ts` است. اگر آن اصلاح را قبلاً اعمال کرده‌اید، لازم نیست حذفش کنید.

## نکات مهم

- در اولین بازشدن پس از ارتقا، مهاجرت داده‌های قبلی به IndexedDB انجام می‌شود. صفحه تا پایان خواندن اطلاعات، کتابخانه را باز نمی‌کند تا کانال‌ها با اطلاعات اولیه جایگزین نشوند.
- `localStorage` مرورگر را به‌صورت دستی پاک نکنید و **Clear site data** نزنید؛ پاک‌کردن داده‌های سایت IndexedDB را هم حذف می‌کند.
- مرورگر و سیستم‌عامل همیشه محدودیت واقعی فضای دیسک دارند؛ هیچ برنامهٔ وبی قادر به حذف سهمیهٔ فیزیکی مرورگر نیست.
- اگر هنگام واردکردن یک کتابخانهٔ بسیار بزرگ، هشدار ذخیره‌سازی ظاهر شد، از بخش تنظیمات Backup بگیرید. بدون رفع کمبود فضای دیسک، حفظ دائمی داده تضمین نمی‌شود.
- برای تغییر حد بازنویسی HLS در Worker شخصی، کد Worker جدید را نیز Deploy کنید؛ این Patch جلوی محدودیت‌های پلتفرم Cloudflare را نمی‌گیرد.
