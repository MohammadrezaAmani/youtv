# ارتقا به YouTV v0.20.0 — پالایش DNS منابع در GitHub Actions

این Patch باید روی **v0.19.0** اعمال شود (نسخه v0.19 همراه اصلاحات TypeScript).

## رفتار جدید

- هنگام پایش مرورگر، اگر تست HTTP به‌دلیل CORS یا خطای اتصال قابل نتیجه‌گیری نباشد، DNS-over-HTTPS بررسی می‌شود. `NXDOMAIN` و نبود هر دو رکورد `A/AAAA` به وضعیت «قطع» منتهی می‌شوند. خطاهای موقت و DNS `SERVFAIL` همچنان «نامشخص» می‌مانند.
- GitHub Actions روی `push` به شاخه `main`، اجرای دستی و دوشنبه‌ها به‌صورت هفتگی: فایل‌های `apps/web/public/sources/` و `apps/web/public/default.m3u8` را می‌خواند؛ URLها را تجمیع و تکراری‌ها را جدا می‌کند؛ DNS هر **هاست یکتا** را بررسی می‌کند؛ و فقط URLهای دارای رکورد `A` یا `AAAA` را در نسخه منتشرشده قرار می‌دهد.
- نسخه اصلی منابع و `README.md`ها در Git حذف/دست‌کاری نمی‌شوند. نسخه پالایش‌شده هر سورس با همان ساختار پوشه در مسیر `_verified/collections/` ساخته می‌شود و از صفحه Playlists قابل فعال یا غیرفعال‌کردن است.
- پلی‌لیست تجمیعی `_verified/online.m3u8` به‌عنوان `default.m3u8` در Checkout موقت CI جایگزین می‌شود تا شبکه‌های مرده از کتابخانه پیش‌فرض حذف شوند. برنامه با تغییر digest، اطلاعات قدیمی پیش‌فرض را تازه می‌کند و Favorites را برای URLهای باقی‌مانده حفظ می‌کند.
- در نسخه منتشرشده، فایل‌های خام منابع و شبکه‌های آرشیوشده کپی نمی‌شوند؛ فقط سورس‌های پالایش‌شده، READMEهای مرتبط، گزارش خلاصه و فهرست DNS منفی در دسترس‌اند.

## آرشیو و گزارش

در تب **Actions → Deploy YouTV to GitHub Pages**، برای هر اجرای موفق/ناموفق، Artifact با عنوان `youtv-iptv-dns-archive` را دریافت کنید. فایل‌ها:

- `nxdomain.m3u8`: دامنه‌های غیرموجود از دید Resolver.
- `no_address.m3u8`: دامنه‌های بدون رکورد IP.
- `uncertain.m3u8`: timeout، SERVFAIL و خطاهای غیرقطعی. این‌ها «مرده قطعی» نیستند.
- `private.m3u8`: آدرس‌های غیرعمومی/محلی، که اعتبارسنجی و انتشار عمومی آن‌ها مناسب نیست.
- `duplicates.m3u8` و `duplicate_origins.json`: ورودی‌های تکراری و محل اصلی آن‌ها.
- `invalid.json` و `skipped_files.json`: آدرس‌های نامعتبر/فایل‌های HLS محلیِ قابل‌تشخیص‌نبودن با DNS.
- `domains.json` و `report.json`: وضعیت میزبان‌ها و گزارش تجمیع.

Artifactها تا ۹۰ روز نگه‌داری می‌شوند. اصل فایل‌ها در مخزن باقی می‌ماند و قابل بازیابی است.

**نکته مهم:** این مرحله فقط وجود دامنه در DNS را اثبات می‌کند؛ بازشدن HTTP، Geo-block، User-Agent، Codec و پخش سالم را تأیید نمی‌کند. برای تأیید قابلیت پخش باید تست HTTP/HLS جداگانه انجام شود. در خروجی «DNS-resolved» به‌جای «کاملاً سالم» به‌کار رفته است.

## دستورات

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.19.0-to-v0.20.0.patch
git apply ~/Downloads/YouTV-v0.19.0-to-v0.20.0.patch

python3 -m unittest discover -s scripts -p 'test_curate_iptv_sources.py'
bun run check
bun run test
bun run build
```

**اجرا روی همه داده‌های واقعی** تنها بعد از Commit و Push فایل‌های `sources` در GitHub Actions انجام می‌شود. این محیط به فولدر محلی ۵۶ هزار ورودی شما دسترسی ندارد، پس نتیجه DNS واقعی آن‌ها اینجا ادعا نشده است.

**احتیاط:** اگر URLهای منابع توکن یا Credential خصوصی دارند، قرار دادنشان در GitHub Pages یا مخزن عمومی آن‌ها را افشا می‌کند. بهتر است قبل از Push محرمانگی سورس‌ها بررسی شود.
