# YouTV v0.6 — اصلاح بافر، تست سیگنال و دسته‌بندی‌ها

این فایل تغییرات نسبت به YouTV **v0.5.0** را شرح می‌دهد و نیاز به جایگزین کردن ZIP پروژه ندارد.

## نصب Patch

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0
git apply --check ~/Downloads/YouTV-v0.5.0-to-v0.6.0.patch
git apply ~/Downloads/YouTV-v0.5.0-to-v0.6.0.patch
bun install
bun run check
bun run test
bun run build
bun run dev
```

اگر پروژه در مسیر دیگری است، دستور `cd` را مطابق مسیر واقعی تغییر بده. اگر `git apply --check` خطا داد، Patch را با `--reject` اعمال نکن؛ نسخه فعلی فایل‌های پروژه را با v0.5 مطابقت بده.

## پخش زنده

- `hls.js` اکنون `startFragPrefetch` را فعال می‌کند و برای حدود ۴۲ ثانیه بافر پیش‌رو تلاش می‌کند (با سقف بافر ۶۰ ثانیه و ۶۴ MiB). این اعداد برای پخش معمولی HLS انتخاب شده‌اند و بسته به سرعت/بیت‌ریت و وضعیت سرور تغییر می‌کنند.
- `liveSyncDurationCount=3` و `liveMaxLatencyDurationCount=7` فاصله امن نسبت به لبه پخش زنده را مدیریت می‌کنند.
- Watchdog اگر ویدئو بیش از ۲٫۲ ثانیه متوقف شود، شکاف کوچک بافر یا عقب‌افتادگی شدید Live را کنترل می‌کند، سپس بارگذاری را مجدداً راه می‌اندازد و فقط پس از زمان طولانی‌تر سراغ بازیابی کامل می‌رود.
- صفحه Diagnostics اکنون تعداد قطعات بافرشده، مدت دریافت آخرین قطعه، رویدادهای Buffering و مقدار بافر پیش‌رو را نشان می‌دهد. این داده‌ها برای تشخیص مشکل سرور منبع یا شبکه کاربرد دارند.
- تنظیم کیفیت‌های واقعی موجود حفظ شده است. هیچ کیفیتی با Transcoding جعلی تولید نمی‌شود.
- اگر خود منبع HLS قطعات را دیر منتشر کند، سرور اجازه دانلود زودتر ندهد یا پهنای باند کافی نباشد، هیچ تنظیم کلاینتی نمی‌تواند قطعه تولیدنشده را زودتر دریافت کند. بررسی Network مرورگر و Diagnostics همچنان لازم است.

## صفحه تست سیگنال

- گزینه اسکن روی مجموعه **فیلترشده** کار می‌کند. فیلترهای گروه، تگ، منبع، نام و وضعیت اتصال هم‌زمان اعمال می‌شوند.
- تمام نتیجه‌ها از طریق صفحه‌بندی ۱۰۰تایی قابل مشاهده‌اند؛ محدودیت ۳۰۰ نتیجه حذف شده است.
- با انتخاب یک شبکه وارد صفحه پخش می‌شوی. انتخاب گروه، کتابخانه را با فیلتر همان گروه باز می‌کند.
- نتیجه Online/Offline/Unknown/Untested در کارت‌های کتابخانه و دکمه‌های فیلتر بالای کتابخانه منعکس می‌شود.
- CORS نامشخص با Offline قطعی اشتباه گرفته نمی‌شود. تست از نوع HTTP/HLS است نه ICMP Ping.

## دسته‌بندی‌ها

از منوی «گروه‌ها» می‌توان تمام گروه‌های پلی‌لیست را با جست‌وجو و مرتب‌سازی بر اساس نام، تعداد کانال یا علاقه‌مندی‌ها دید. انتخاب هر گروه مستقیماً کتابخانه فیلترشده را باز می‌کند. گروه‌های بدون عنوان نیز جدا نمایش داده می‌شوند.

## Cloudflare

راهنمای قدم‌به‌قدم در بالای صفحه مدیریت پروکسی قرار دارد؛ تفاوت میان `API Token` مدیریتی و `PROXY_TOKEN` پخش توضیح داده شده است. مقدار `ADMIN_TOKEN` باید مستقل باشد. کلید **Global API Key** را وارد نکن.

## تست

`bun run test` اکنون تست‌های Vitest (`.test.ts`) و Node test runner (`.test.mjs`) را **جدا** اجرا می‌کند تا خطای `No test suite found` از ترکیب رانرها رخ ندهد. برای این بخش Node.js 22 یا جدیدتر لازم است.
