# YouTV 0.9 — اصلاح کامل هدر، سایدبار و اتصال منحنی

این Patch فقط برای سورس **YouTV v0.8** است و کانال‌ها یا تنظیمات ذخیره‌شده را تغییر نمی‌دهد.

## تغییرات

- بازسازی مستقل Shell با کلاس‌های `yt-*`؛ استایل‌های قدیمی هدر و سایدبار دیگر روی آن اعمال نمی‌شوند.
- Layout مشابه ساختار داشبورد آناما: هدر افقی، سایدبار سمت راست، محتوای اصلی سمت چپ، و گوشه منحنی در اتصال بالایی.
- دکمه جمع/بازکردن با عرض‌های مشخص و ذخیره حالت در LocalStorage (`youtv:sidebar-collapsed`).
- در حالت فشرده فقط آیکون‌ها با Tooltip و دسترسی کیبورد نمایش داده می‌شوند. جستجوی منو می‌تواند سایدبار را دوباره باز کند.
- در موبایل: هدر دو ردیفه، منوی کشویی واقعی با لایه تاریک پشت آن، بستن با Escape/دکمه، و Bottom Navigation اختصاصی.
- طراحی جدید جستجوی سراسری و جستجوی بخش‌ها بدون Focus Ring.
- تم روشن/تاریک از دکمه کوچک هدر قابل جابه‌جایی است.

## اعمال Patch

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.8.0-to-v0.9.0.patch
git apply ~/Downloads/YouTV-v0.8.0-to-v0.9.0.patch

bun install
bun run check
bun run test
bun run build
bun run dev
```

این Patch بر پایه سورسی است که Patch نسخه v0.8 روی آن اعمال شده است. در صورت وجود تغییرات دستی، ابتدا تضادهای Patch را بررسی کنید.
