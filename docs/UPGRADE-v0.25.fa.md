# YouTV v0.25 — Origin ثابت و توکن اختیاری در رابط

- آدرس مبنای CORS در خود Worker **`https://mohammadrezaamani.github.io`** در کد Worker ثابت شده است. توسعه روی `localhost`، `127.0.0.1` و `[::1]` با HTTP/HTTPS نیز بدون تعریف `ALLOWED_ORIGINS` مجاز است.
- `ALLOWED_HOSTS` به‌صورت پیش‌فرض `*` است؛ ورود جداگانه دامنه استریم لازم نیست. اتصال به IP مستقیم و میزبان داخلی همچنان محدود است.
- در فرم «افزودن Worker»، گزینه «این Worker توکن دسترسی دارد» به‌صورت پیش‌فرض غیرفعال است. هنگام غیرفعال بودن، ورودی توکن اصلاً نمایش داده نمی‌شود و پروفایل با `token: ''` ذخیره می‌شود؛ بنابراین درخواست‌های `/proxy`، `/probe` و `/text` فاقد `key` هستند.
- اگر در Cloudflare مقدار غیرخالی `PROXY_TOKEN` تعریف کنی، گزینه توکن را روشن کن و همان مقدار را بده. **اگر بدون توکن می‌خواهی، متغیر `PROXY_TOKEN` را کاملاً حذف کن**؛ پاک کردن فقط توکن داخل YouTV برای Worker محافظت‌شده کافی نیست.
- عملیات مدیریتی Cloudflare همچنان `ADMIN_TOKEN` جداگانه (و API Token محدود) لازم دارند؛ این دو ربطی به دسترسی پخش کانال ندارند. مسیر مدیریتی از Origin پیش‌فرض بدون تنظیم دستی `ALLOWED_ORIGINS` هم کار می‌کند، اما `ALLOWED_ORIGINS=*` برای مدیریت رد می‌شود.

## استقرار

1. Patch نسخه v0.24 به v0.25 را اعمال کن و وب‌سایت را منتشر کن.
2. اگر Worker را در Cloudflare Dashboard ساخته‌ای، **فایل جدید** `apps/web/public/dashboard-worker.mjs` را جایگزین کد Worker کن و **Deploy** بزن. Push کردن Frontend به GitHub به‌تنهایی کد Worker را آپدیت نمی‌کند.
3. خروجی `https://round-fog-1d8f.mr4016a1382.workers.dev/health` باید `version: 0.25.0` داشته باشد. مسیر `/capabilities` با نبود `PROXY_TOKEN` باید `authentication: none` را گزارش کند.
4. در YouTV اگر از قبل توکنی ذخیره شده، روی «تغییر توکن» بزن و مقدار خالی را ذخیره کن؛ در صورت کش PWA، سایت را با نسخه جدید باز کن.

**هشدار:** Worker عمومی با `ALLOWED_HOSTS=*` و بدون `PROXY_TOKEN` می‌تواند توسط دیگران مصرف شود؛ این تنظیم سهمیه و هزینه احتمالی Worker را در معرض استفاده دیگران قرار می‌دهد.
