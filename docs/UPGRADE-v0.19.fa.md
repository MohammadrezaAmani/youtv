# YouTV v0.19 — پخش موبایل و جابه‌جایی Multi-view

## تغییرات

- انتخاب پخش بومی HLS روی iPhone/iPad، حتی اگر hls.js روی دستگاه پشتیبانی شود؛ و نگه‌داشتن hls.js برای دسکتاپ/Android در صورت امکان
- حذف `crossorigin=anonymous` از مسیر HLS بومی (تا سرورهای استریم بدون CORS لازم برای hls.js روی iOS بی‌دلیل رد نشوند)
- توقف تلاش خودکار ناموفق پخش صدا روی iOS و ارائه دکمه Play برای شروع با لمس کاربر
- شناسایی HTTP مسدودشده روی سایت HTTPS؛ استفاده خودکار از Worker اگر حالت Auto و Worker فعال باشد؛ در غیر این صورت خطای روشن
- تشخیص فرمت HLS برای `*.m3u8` حتی وقتی Format روی Auto است تا Worker Manifest و Segmentهایش را درست بازنویسی کند
- همان اصلاحات در پلیرهای Multi-view و فعال‌سازی صدا هنگام لمس دکمه مربوط به هر tile
- انتقال دکمه Multi-view از بالای صفحه به ردیف دکمه‌های زیر پلیر (کنار علاقه‌مندی و عملیات). وقتی Multi-view فعال شود، مدیریت آن زیر Grid قرار می‌گیرد.

## محدودیت‌های واقعی

پخش HLS روی iPhone تضمین‌شده نیست: اگر منبع HTTP روی HTTPS باشد، رمزگذاری/Codec با iOS ناسازگار باشد، امضای لینک منقضی شده باشد یا به هدر User-Agent/Referer نیاز داشته باشد، ممکن است به Worker شخصی سازگار با آن منبع نیاز باشد. همین‌طور همهٔ منابع دسکتاپ روی دستگاه تلفن قابل پخش نیستند. در PWA نصب‌شده، پس از Deploy نسخه جدید باید از بخش Settings به‌روزرسانی PWA اعمال شود یا برنامه دوباره بارگیری شود. برای پیدا کردن دلیل دقیق، یک URL نمونه به‌همراه نسخه iOS و پیام خطای پلیر لازم است.
