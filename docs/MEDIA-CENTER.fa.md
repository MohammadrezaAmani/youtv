# مرکز رسانه YouTV

مرکز رسانه فقط از همان فرانت‌اند React/Vite و Cloudflare Worker موجود استفاده می‌کند. هیچ API اختصاصی، Backend، Docker service یا سرور دانلود جدیدی به پروژه اضافه نشده است.

## معماری

- React/Vite: رابط کاربری، تشخیص URL، پلیر و مدیریت عملیات.
- Cloudflare Worker فعلی: رله YouTube/Instagram عمومی، پروکسی HTTP(S)، دریافت باینری، Range، Content-Disposition و بازنویسی HLS/DASH.
- `youtubei.js`: استخراج اطلاعات، فرمت‌ها، Playlist و Transcript عمومی YouTube از داخل مرورگر، با درخواست‌های عبوری از Worker.
- `dash.js`: پخش MPEG-DASH.
- `hls.js` و پخش بومی Safari: پخش HLS.
- `mediabunny`: ترکیب Trackهای صوت/تصویر YouTube و تبدیل مرورگری به MP4، با WebCodecs.
- `fflate`: ساخت ZIP به‌صورت جریانی.
- OPFS: فایل موقت برای دانلود/تبدیل بزرگ؛ File System Access API در مرورگرهای پشتیبانی‌شده برای ذخیره مستقیم. MP4 تبدیل‌شده به‌صورت فایل موقت قابل پیش‌نمایش و دانلود است.
- LocalStorage: تاریخچه و وضعیت Jobها؛ فایل رسانه در آن ذخیره نمی‌شود.

## YouTube

- URLهای Watch، youtu.be، Shorts، Live و Playlist شناسایی می‌شوند.
- پخش با DASH در صورت دسترسی به Manifest؛ در صورت خطای DASH، پلیر رسمی `youtube-nocookie.com` جایگزین می‌شود.
- اطلاعات عنوان، کانال، توضیح، بازدید، تاریخ انتشار، مدت، Thumbnail و فرمت‌های قابل دریافت نمایش داده می‌شود.
- Playlist به‌صورت صفحه‌ای دریافت می‌شود؛ هر مرحله حداکثر ۵۰۰ آیتم است و امکان بارگذاری ادامه وجود دارد.
- فرمت‌های progressive مستقیماً دریافت می‌شوند.
- فرمت‌های adaptive صوت و تصویر جداگانه در مرورگر با `mediabunny` به MP4 ترکیب می‌شوند. این کار به WebCodecs و Codecهای قابل پشتیبانی مرورگر وابسته است.
- زیرنویس/Transcript قابل دسترس به WebVTT صادر می‌شود.
- Thumbnail و Metadata JSON قابل دریافت‌اند.
- Playlist انتخاب‌شده به ZIP تبدیل می‌شود؛ فرمت و کیفیت در حد فرمت‌های عمومی قابل دریافت YouTube انتخاب می‌شود.

محدودیت‌ها: ویدئوهای خصوصی، نیازمند ورود، برخی ویدئوهای محدودشده، Live و فرمت‌های DRM/SABR ممکن است قابل دریافت نباشند. این پیاده‌سازی احراز هویت YouTube یا دورزدن DRM انجام نمی‌دهد. دسترسی استخراج عمومی ممکن است با تغییرات YouTube موقتاً مختل شود.

## Instagram

- URL عمومی Post، Reel و TV شناسایی می‌شود.
- اطلاعات صفحه و رسانه‌های عمومی از HTML/JSON عمومی استخراج می‌شود.
- عکس‌ها و ویدئوهای Carousel به‌صورت جداگانه قابل دریافت‌اند.
- چند رسانه انتخاب‌شده در یک ZIP قرار می‌گیرند.
- در صورت نبود داده عمومی قابل استخراج، Embed رسمی نمایش داده می‌شود.

محدودیت‌ها: محتوای خصوصی، نیازمند ورود، Storyهای محافظت‌شده و پست‌هایی که مبدأ فایل رسانه را در پاسخ عمومی افشا نمی‌کند قابل تضمین نیستند. Cookie یا رمز عبور حساب کاربر جمع‌آوری نمی‌شود.

## URL مستقیم و فایل‌ها

- تشخیص از روی URL، MIME و Probe محدود Worker انجام می‌شود.
- ویدئو: MP4، M4V، MKV، WebM، MOV، AVI، FLV، WMV، MPEG، TS، M2TS، OGV، MXF، VOB، RM/RMVB و فرمت‌های شناخته‌شده دیگر.
- صوت: MP3، M4A، AAC، OGG، Opus، WAV، FLAC، ALAC، AIFF، WMA، AC3 و فرمت‌های شناخته‌شده دیگر.
- تصویر: JPEG، PNG، GIF، WebP، AVIF، BMP، TIFF، SVG و فرمت‌های شناخته‌شده دیگر.
- PDF پیش‌نمایش می‌شود؛ سایر فایل‌های ناشناخته نیز به‌صورت باینری قابل دانلودند.
- فایل اصلی بدون تبدیل از Worker به‌صورت Stream دریافت می‌شود.
- Range و HTTP 206 حفظ می‌شود. در دانلود مستقیم مرورگر، Resume به پشتیبانی Range سرور و Download Manager مرورگر وابسته است.

## آرشیو HLS

- Playlist رسانه‌ای یا Master Playlist دریافت می‌شود.
- در Master، بالاترین Variant انتخاب می‌شود و Audio/Subtitle/Video renditionهای گروه انتخاب‌شده در صورت وجود به آرشیو اضافه می‌شوند.
- قطعات، initialization map، کلید AES-128 با KEYFORMAT identity، Byte Range و زیرنویس مستقیم WebVTT پشتیبانی می‌شوند.
- Playlist محلی با مسیرهای نسبی و ساختار ZIP تولید می‌شود.
- برای Live، فقط پنجره فعلی Playlist/DVR که مبدأ تبلیغ کرده ذخیره می‌شود و `ENDLIST` به نسخه آرشیوی اضافه می‌شود؛ این ضبط کامل پخش نیست.
- LL-HLS Partهای ناقص، DRM، SAMPLE-AES و KEYFORMATهای غیر identity به‌عنوان آرشیو آفلاین پشتیبانی نمی‌شوند.

## آرشیو MPEG-DASH

- MPD ثابت VOD با SegmentTemplate، SegmentList و SegmentBase پشتیبانی می‌شود.
- Templateهای ارث‌بری‌شده از MPD/Period/AdaptationSet/Representation ادغام می‌شوند.
- `$RepresentationID$`، `$Number$`، `$Time$`، `$Bandwidth$` و الگوهای عددی قالب‌بندی‌شده هنگام ساخت آرشیو به فایل‌های محلی تبدیل می‌شوند.
- SegmentList و SegmentBase با Range پشتیبانی می‌شوند.
- BaseURLهای راه دور با مسیرهای محلی جایگزین می‌شوند.
- MPD زنده/Dynamic فقط برای پخش است؛ آرشیو کامل آن ساخته نمی‌شود.
- ContentProtection/DRM آرشیو نمی‌شود.

## صف دانلود

- Jobها در صف ترتیبی اجرا می‌شوند تا مصرف حافظه کنترل شود.
- وضعیت، سرعت/بایت دریافت‌شده، درصد در صورت معلوم‌بودن طول، خطا و لغو نمایش داده می‌شود.
- دانلود ZIP و Stream با AbortSignal قابل لغو است.
- File System Access API برای ذخیره مستقیم در مرورگرهای پشتیبانی‌شده استفاده می‌شود.
- در مرورگرهای دیگر OPFS برای فایل موقت استفاده می‌شود؛ اگر OPFS موجود نباشد، fallback حافظه برای فایل‌های بزرگ محدود است.
- تاریخچه فقط Metadata Jobها را نگه می‌دارد، نه فایل‌های دانلودشده.

## محدودیت‌های مرورگر و مبدأ

- Worker می‌تواند CORS مرورگر را برای مقصدهای عمومی از مسیر خودش حل کند، اما محدودیت IP، Geo-block، Token منقضی، Referer/Origin ضدربات، Login، DRM و محدودیت‌های قانونی/شرایط سرویس را حذف نمی‌کند.
- فایل‌های MKV/AVI و Codecهای خاص ممکن است دانلود شوند ولی در `<video>` قابل پخش نباشند. تبدیل MP4 با `mediabunny` به پشتیبانی WebCodecs مرورگر و منابع دستگاه وابسته است.
- بدون OPFS یا File System Access، فایل‌های حجیم ممکن است از سقف حافظه fallback عبور کنند.
- هیچ داده ساختگی یا لینک نمونه به فهرست رسانه‌ها اضافه نشده است.

## اصلاحات نسخه 0.36.1

- BaseURL مربوط به DASH از ساختار مسیر نسخه‌دار استفاده می‌کند؛ اطلاعات مقصد و توکن در ساخت URL نسبی قطعه گم نمی‌شوند. مجوز و allowlist در هر درخواست دوباره بررسی می‌شود.
- MPD بازگشتی از URL بدون پسوند حتی در صورت دریافت hint قدیمی HLS تشخیص داده می‌شود.
- کد استخراج‌شده Player یوتیوب در iframe با origin مستقل و CSP محدود اجرا می‌شود؛ دسترسی مستقیم به اطلاعات و ذخیره‌سازی برنامه ندارد.
- لغو یا شکست نوشتن فایل، دانلود نیمه‌تمام را تکمیل‌شده گزارش نمی‌کند. دانلود واگذارشده به مرورگر وضعیت جداگانه دارد.
- ZIP به شکل streaming با backpressure ساخته می‌شود. به دلیل ZIP32، برای آرشیوهای نزدیک 4GB باید مجموعه را به چند بخش تقسیم کرد.
- پیش‌نمایش MP4 پس از تبدیل در همان صفحه فعال است و دکمه جداگانه ذخیره خروجی تبدیل‌شده دارد.
- نسخه Worker و فایل قابل Copy/Download هر دو 0.36.1 هستند.

تست‌های محلی شامل سناریوهای مصنوعی صرفاً برای آزمون نرم‌افزار هستند، نه داده‌های نمونه در رابط تولید. دسترسی واقعی به YouTube و Instagram، نصب وابستگی‌ها، Build کامل و پخش مرورگر روی شبکه مقصد هنوز نیازمند آزمون هستند.
