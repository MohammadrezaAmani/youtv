# YouTV v0.13.0

این Patch روی سورس **v0.12.0** اعمال می‌شود و داده‌های شخصی و LocalStorage را حذف نمی‌کند.

## تغییرات

- تم‌ها مستقل‌اند: `dark` رز تیره، `light` رز روشن، `mint` سبز روشن. تم‌های قبلی `emerald`، `oled`، `ocean` و `violet` همچنان موجودند. انتخاب رنگ از بخش Settings → Appearance انجام می‌شود؛ دکمه هدر فقط حالت روشن/تیره همان خانواده را در خانواده رز یا سبز جابه‌جا می‌کند.
- Multi-view از دکمه فعال می‌شود؛ در صورت وجود شبکه مرتبط، شبکه دوم را اضافه می‌کند. شبکه‌های بیشتر را می‌توان با دکمه `+` کنار شبکه‌های مرتبط یا دکمه «افزودن شبکه» و جست‌وجوی داخلی انتخاب کرد. سقف نسخه فعلی ۴ شبکه است.
- هر tile موتور HLS مستقل، کنترل پخش، انتخاب صدای فعال، ورود به صفحه شبکه، خروج از چیدمان و امکان تغییر اندازه دارد. برای جلوگیری از مسدودشدن autoplay، پخش چندگانه ابتدا بی‌صدا آغاز می‌شود؛ صدای یک tile در هر لحظه می‌تواند فعال باشد. مصرف CPU و شبکه به تعداد کانال‌ها و codec بستگی دارد.
- در موبایل، دکمه منو به سمت مقابل لوگو منتقل شد و جست‌وجوی اصلی در **همان ردیف هدر** قرار گرفت.
- چیدمان و عرض تصویر، نام و دکمه‌های شبکه‌های مرتبط در موبایل اصلاح و تعداد اولیه به ۱۲ مورد محدود شده؛ دکمه «نمایش بیشتر» وجود دارد.
- نشانگر LIVE از روی کارت کانال‌های کتابخانه و صفحه خانه حذف شد. قابلیت رفتن به Live Edge در پلیر حفظ شده است.

## اعمال Patch

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.12.0-to-v0.13.0.patch
git apply ~/Downloads/YouTV-v0.12.0-to-v0.13.0.patch

bun install
bun run check
bun run test
bun run build
bun run dev
```

اگر `git apply --check` خطا داد، Patch را به‌اجبار اعمال نکن؛ ابتدا تفاوت فایل‌های محلی با نسخه v0.12 را بررسی کن.
