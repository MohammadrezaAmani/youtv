# اصلاح M3U Import و منابع محلی — YouTV v0.14

## اعمال Patch

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0
git apply --check ~/Downloads/YouTV-v0.13.0-to-v0.14.0.patch
git apply ~/Downloads/YouTV-v0.13.0-to-v0.14.0.patch
bun run sources:check
bun run check
bun run test
bun run build
bun run dev
```

## منابع پوشه‌ای

تمام فایل‌های `.m3u` و `.m3u8` داخل `apps/web/public/sources/` و زیرپوشه‌ها در حالت توسعه در `/#/playlists` نمایش داده می‌شوند؛ هیچ فایل جدیدی بدون تصمیم کاربر فعال نمی‌شود.

`bun run sources:check` شمارش ورودی‌های هر فایل را از دیسک چاپ می‌کند. برای بررسی API فهرست در حالت توسعه: `http://localhost:5173/sources/index.json`. فایل‌های ZIP خودکار استخراج نمی‌شوند. فایل‌های HLS (یک استریم به‌جای فهرست کانال) در فهرست قابل مشاهده‌اند اما به عنوان Playlist شبکه Import نمی‌شوند.

هنگام افزودن فایل در حالت اجرای Vite، اعلان تغییر فایل موجب تازه‌سازی فهرست می‌شود؛ دکمه «به‌روزرسانی» نیز برای بازخوانی دستی موجود است. در GitHub Pages فقط بعد از Build و Deploy جدید، فهرست و فایل‌ها به‌روز می‌شوند؛ مرورگر امکان فهرست‌کردن پوشه سیستم کاربر را ندارد.

## Import دستی

فایل‌های Importشده از دستگاه در بخش «منابع ثبت‌شده» دیده می‌شوند. این فایل‌ها خودکار وارد پوشه `public/sources/` نمی‌شوند. بعد از Import، به صفحه منابع هدایت می‌شوی.

## اصلاح داده‌های واردشده در نسخه قبل

در شروع برنامه، نام کانال‌هایی که به‌اشتباه با `tvg-id=...` ذخیره شده بودند، از روی فراداده همان نام اصلاح می‌شوند. Favorites، تگ‌ها و شناسه‌ها حفظ می‌شوند. برای بازیابی دقیق مشخصات دیگر می‌توان همان فایل را دوباره Import کرد؛ با همان نام منبع، به‌جای ایجاد منبع تکراری، اطلاعات منبع قبلی به‌روزرسانی می‌شود.

## بررسی فهرست منابع

اگر سایت فهرست پوشه را نشان نمی‌دهد، داخل همان ریشه پروژه اول `bun run sources:check` را بزن. اگر تعداد فایل‌ها آنجا درست بود، `bun run dev` را اجرا کن و در مرورگر نشانی `http://localhost:5173/sources/index.json` را باز کن. فایل‌های `public/sources/` در GitHub Pages فقط پس از Build/Deploy دیده می‌شوند. هنگام Build یک `index.json` برای همان محتوا داخل خروجی ساخته می‌شود.

**توجه:** فهرست منبع با شبکه‌های فعال یکی نیست. تا زمانی که خودت گزینه فعال‌سازی آن فایل را نزنی، کانال‌هایش وارد کتابخانه نمی‌شوند.
