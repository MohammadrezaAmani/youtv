# YouTV v0.12 — پخش و منابع محلی

## اعمال Patch روی نسخه 0.11

```bash
cd ~/Downloads/YouTV-Core-v0.3.0/youtv-core-v0.3.0

git apply --check ~/Downloads/YouTV-v0.11.0-to-v0.12.0.patch
git apply ~/Downloads/YouTV-v0.11.0-to-v0.12.0.patch

bun install
bun run check
bun run test
bun run build
bun run dev
```

## پوشه منابع

پلی‌لیست‌های واقعی M3U و M3U8 را داخل مسیر زیر (یا زیرپوشه‌های آن) کپی کن:

```text
apps/web/public/sources/
```

پس از اجرای `bun run dev`، به صفحه **پلی‌لیست‌ها → منابع داخل پوشه** برو. نام فایل‌ها و تعداد ورودی‌های واقعی هرکدام نشان داده می‌شود؛ فعال‌سازی هر منبع کاملاً اختیاری است و کانال‌های منبع غیرفعال پنهان می‌مانند. اطلاعات شخصی مثل Favorites و Tags در فعال/غیرفعال‌کردن حفظ می‌شود. فایل M3U8 که یک *HLS Video Manifest* باشد، لیست IPTV نیست و به‌عنوان پلی‌لیست شبکه فعال نمی‌شود؛ لینک آن را جداگانه به‌عنوان کانال اضافه کن.

در GitHub Pages امکان خواندن یک پوشه دلخواه روی کامپیوتر بازدیدکننده وجود ندارد. فهرست منابع داخل `sources/index.json` هنگام Build ایجاد می‌شود؛ پس از تغییر فایل‌های پوشه، سایت را **دوباره Build و Deploy** کن. در حالت توسعه، فهرست منابع از همان پوشه فعلی به‌روز خوانده می‌شود. هیچ فایل یا شبکه ساختگی همراه این قابلیت اضافه نشده است.

## پلیر

- ضبط در منوی دکمه دایره‌ای قرمز **داخل خود پلیر** است؛ نوار همیشگی ضبط زیر ویدئو حذف شد.
- وضعیت‌های `loading HLS` و `Direct` زیر ویدئو حذف شدند. برای خطایابی همچنان Diagnostics قابل دسترسی است.
- دکمه Rotate داخل کنترل‌ها، در مرورگرهایی که اجازه بدهند جهت صفحه را در Fullscreen به Landscape تغییر می‌دهد؛ در سایر مرورگرهای دارای Fullscreen تلاش می‌کند تصویر ویدئو را بچرخاند.
- عدد Delay، در صورت وجود اطلاعات زنده HLS، **تأخیر تقریبی تا Live Edge** است، نه تأخیر واقعی سیگنال ماهواره نسبت به زمان دیواری.
- سرریز فیلترهای موبایل و دایره‌های صورتی کارت‌ها اصلاح شدند.
