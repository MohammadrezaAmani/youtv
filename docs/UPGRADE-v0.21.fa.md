# ارتقا به YouTV v0.21.0

این Patch مخصوص مخزن **YouTV v0.20.0** بعد از کامیت `62fdd6d` است.

## اصلاحات

- دو متن توضیحی اضافی از صفحه پایش وضعیت شبکه‌ها حذف شده‌اند.
- خطای مستقیم `Failed to fetch`، و معادل‌های مرورگرهای Safari/Firefox، در تست سلامت مرورگر **قطع** ثبت می‌شوند. در صورت موفق بودن Worker نتیجه واقعی آن حفظ می‌شود؛ لغو تست و timeout همچنان نامشخص‌اند. NXDOMAIN همچنان علت دقیق DNS را نشان می‌دهد.
- فهرست «شبکه‌های مرتبط» در عرض‌های میانی به زیر پلیر منتقل می‌شود و اسامی طولانی باعث اسکرول افقی نمی‌شوند.
- کنترل‌های پلیر با عرض خود ویدئو تنظیم می‌شوند؛ دکمه تمام‌صفحه در عرض‌های محدود باقی می‌ماند و ابزارهای جانبی در منوی «بیشتر» قابل استفاده‌اند.
- تست‌های Worker دیگر به فلگ ناسازگار Node وابسته نیستند و فایل‌های `.mjs` با تست‌رانر Bun اجرا می‌شوند.

## نصب

دستورات باید از **ریشه مخزن فعلی** اجرا شوند، نه مسیر یک پوشه فشرده قدیمی:

```bash
cd /Users/more/dev/youtv
git status --short
git apply --check ~/Downloads/YouTV-v0.20.0-to-v0.21.0.patch
git apply ~/Downloads/YouTV-v0.20.0-to-v0.21.0.patch

python3 -m unittest discover -s scripts -p 'test_curate_iptv_sources.py'
bun run check
bun run test
bun run build
```

پس از اعمال Patch، نتایج قبلی پایش به‌صورت خودکار بازنویسی نمی‌شوند؛ برای دیدن طبقه‌بندی جدید، **تست مجدد شبکه‌ها** را اجرا کنید.

**توجه:** مرورگر ممکن است به‌دلیل CORS نیز `Failed to fetch` بدهد. با توجه به رفتار درخواستی، چنین خطایی در صفحه پایش «قطع» نمایش داده می‌شود؛ این برچسب به‌تنهایی اثبات خرابی سرور اصلی نیست.
